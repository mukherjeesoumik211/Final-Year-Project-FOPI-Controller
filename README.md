# Design and Simulation of an Optimised Fractional-Order PI (FOPI) Controller for a PV Inverter

## 1. Project Overview
This project focuses on designing and simulating an optimised Fractional Order Proportional-Integral (FOPI) controller for a Photovoltaic (PV) inverter to improve control performance and system stability.

## 2. Project Objectives
- To design an optimised FOPI controller for a PV inverter.
- To improve the dynamic response of the inverter control system.
- To study system stability and controller performance.
- To analyse the effectiveness of fractional-order control.

## 3. Project Description
The project involves developing a fractional-order PI controller and implementing its control strategy in a PV inverter system. The controller is designed to provide improved flexibility and control performance compared with conventional PI control.

- Simulation and control system analysis tools

## 5. Key Technologies

## 6. Methodology

- Design of the Fractional Order PI controller.

- Analysis of controller performance through simulation.
